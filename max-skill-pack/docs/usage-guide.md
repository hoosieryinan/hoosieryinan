# Usage Guide

## Basic pattern

```text
Use [skill-name].
Goal: [Outcome]
Audience: [Audience]
Context: [Background]
Raw notes: [Notes]
Output format: [Email / table / checklist / plan / script]
Language: [English / Chinese / bilingual]
Constraints: [Deadline, tone, privacy limits]
```

```text
Use max-workplace-manager. Plan my week from these tasks. Show priority, stakeholder impact, and next action.
```
