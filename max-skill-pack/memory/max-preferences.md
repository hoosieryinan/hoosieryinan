# Max Preferences

## Output preferences
- Ready-to-use templates
- Copy-paste friendly documents
- Tables, checklists, structured bullets, and step-by-step guides
- Recommendations framed as "what should I do next"
- Executive summary first for management communication
- Root cause, impact, options, recommendation, and next steps for technical topics

## Complex task structure
1. Situation summary
2. Key issue
3. Options
4. Recommendation
5. Risks
6. Next action

## Email preferences
- Include subject line and final body
- Concise, polite, diplomatic, action-oriented
- Make the ask clear
- Avoid blame unless escalation requires firmer language

## Script preferences
- Comments
- Error handling
- Logging
- Safe assumptions
- Dry-run or validation mode when appropriate

## Project document preferences
Include scope, assumptions, dependencies, risks, rollback, owner, timeline, and acceptance criteria.
